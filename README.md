# Документация по развертыванию
 
## Зависимости:
[golang версия 1.23](https://go.dev/dl/)

[bun.js](https://bun.sh/) | или любой другой пакетный менеджер:: не рекомендуется


## Команды по развертыванию

#### Backend для елк (госвы)

1) перед начало работы с бэкендом для елк нужно выполнить команду `cd /elk`
2) после того как вы перешли в папку необходимо выполнить команду `go mod download`
3) после чего необходимо выполнить `go run main.go`

**Поздравляю бэкенед для взаимодействия с елк работает :)**

### Backend (основной)

1) перед начало работы с бэкендом для елк нужно выполнить команду `cd /backend`
2) после того как вы перешли в папку необходимо выполнить команду `go mod download`
3) после нужно перейти в ядро сервера `cd /core/`
4) после чего необходимо выполнить `go run main.go`

**Поздравляю основной бэкенд работает :)**

#### Fronted 

1) перед начало работы с фронтендом нужно выполнить команду `cd /fronted`
2) после того как вы скопировали команду выше нужно подкачать зависимости `bun i`
3) и наконец финальным этапом будет запустить фронтенд `bun dev`
